Tu dois recréer ce site "http://www.tirtey-reisen.de/startseite.html" en utilisant Astro et Tailwind CSS le site doit etre en langue allemande.
Pour les images tu peux utiliser pour l'instant des images de placeholder. Le site doit être responsive et adapté pour les mobiles. 
voici le menu du site :
- Startseite (Accueil)
- Schülerreisen (Voyages scolaires)
- Gruppenreisen (Voyages en groupe)
- Busvermietung (Location de bus)
- Kontakt (Contact)
